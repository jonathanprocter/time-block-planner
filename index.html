      Google Calendar Setup Guide

      Step 1: Create a Google Cloud Project

      1. Go to Google Cloud Console
      2. Click "Select a project" → "New Project"
      3. Enter a project name (e.g., "Time-Block Planner") and click "Create"

      Step 2: Enable Google Calendar API

      1. In your project, go to "APIs & Services" → "Library"
      2. Search for "Google Calendar API"
      3. Click on it and press "Enable"

      Step 3: Create OAuth 2.0 Credentials

      1. Go to "APIs & Services" → "Credentials"
      2. Click "Create Credentials" → "OAuth client ID"
      3. If prompted, configure the OAuth consent screen:
        • Choose "External" user type
        • Fill in app name, user support email, and developer email
        • Add scopes: calendar.readonly and calendar.events
        • Add your email as a test user
      4. Select "Web application" as application type
      5. Add authorized JavaScript origins:
        • http://localhost:8000 (for local development)
        • http://localhost:3000 (alternative port)
        • Your production domain (if applicable)
      6. Add authorized redirect URIs:
        • http://localhost:8000
        • http://localhost:3000
      7. Click "Create" and copy your Client ID

      Step 4: Create API Key

      1. In "Credentials", click "Create Credentials" → "API key"
      2. Copy the API key
      3. (Optional) Click "Restrict Key" to limit it to Calendar API only

      Step 5: Configure This Application

      1. Paste your Client ID in the field above
      2. Paste your API Key in the field above
      3. Click "Connect Google Calendar"
      4. Authorize the application when prompted

      ⚠️ Important Notes:

      • Local Development: This app must be served via HTTP (not file://). Use a local server: 
        python -m http.server 8000
        or 
        npx http-server -p 8000
      • Security: Your credentials are stored locally in your browser only
      • OAuth Scopes Required:
        • https://www.googleapis.com/auth/calendar.readonly - Read calendar events
        • https://www.googleapis.com/auth/calendar.events - Create/modify events
